# Waveshare Home 1.5.0

Correctness and polish release for the Waveshare ESP32-S3 Touch LCD 3.5-inch local workshop companion.

## Touchscreen

- Keeps the stable Home / Printer / More navigation model with 44px minimum bottom-nav targets.
- Reduces More to six purposeful destinations: Workshop, Filament, Today, Smart Home, Timers, Settings.
- Defaults Home cards to Printer, Filament, Workshop and adds Workshop as a first-class Home card.
- Uses semantic Home-card state colors and dynamic printer identity instead of a hardcoded model.
- Rebuilds Filament and Workshop as component-based operational surfaces.
- Bounds text-heavy Attention, Timers, Activity, System, Rules/Automation, Devices, and Readiness content in scrollable containers.
- Fixes Settings geometry and applies theme changes through a controlled restart.
- Requires a long press to forget Wi-Fi and disables printer controls when their action is not valid.
- Refreshes the active screen instead of rewriting all hidden LVGL screens every second.
- Restores live Modes refresh and replaces the misleading optional-integration readiness percentage with Core / Optional readiness.

## Runtime and state

- Implements explicit Off, Manual, Auto, and Post-print air-mode behavior and clears stale filtration requests.
- Migrates configuration schema to version 5 while preserving user settings and modernizing the old default Home-card trio.
- Adds compact filament attention summaries for low/empty spools.
- Defaults new update-policy configuration to the stable channel.

## Web dashboard

- Replaces Audio with Filament in the primary operating-state row.
- Adds authoritative `printer.printing` and richer filament data to `/api/status`.
- Uses authoritative print state for live controls instead of `progress > 0` inference.
- Adds finite request timeouts for local status/actions.
- Fixes disconnected RSSI presentation, missing top/badge styles, mobile safe-area padding, micro typography, and 44px navigation targets.

## Validation

The branch must pass the Waveshare source/UX regression suite, deployment validation, CSS architecture audit, and the pinned Arduino ESP32-S3 hardware compile before merge/release.
