# Historical release provenance

This directory contains superseded RC manifests and validation reports retained for audit/history only.

Nothing under `releases/archive/` is an active download channel, current candidate, or promotion target. Current source state is declared by `releases/current.json`; the static installer channel is declared by `release.json`.

Historical binaries are not duplicated here. Git history and Actions/release provenance remain the binary history; the tracked `firmware/` directory retains only the current static-download pair and one immediate rollback pair.
