# Archived RC2 trusted-LAN experiment

An early v11.23 RC2 iteration briefly used a station-mode trusted-LAN authentication bypass to speed physical touch testing. That experiment is **not** the mergeable security posture.

The active candidate restores the v11.20 portal/session boundary before validation, native builds, packaging, and promotion. The no-code physical-acceptance helper was removed, and the supported framebuffer capture helper is authenticated again.

This note exists only to explain the historical commits and should not be interpreted as an enabled or supported access mode.
